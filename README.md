# فيديوهات بالديرما

مستودع لإدارة محتوى الفيديوهات القصيرة لمركز **بالديرما** للأمراض الجلدية والتجميل والعناية بالبشرة.

## الهدف

إنتاج فيديوهات قصيرة (ريلز، تيك توك، شورتس) تُعرّف بخدمات المركز، وتقدّم نصائح موثوقة للعناية بالبشرة، وتبني الثقة مع الجمهور بأسلوب طبي واضح ومتّسق مع هوية بالديرما.

## هيكل المستودع

| المجلد | المحتوى |
| --- | --- |
| [`scripts/`](scripts/) | نصوص الفيديوهات الجاهزة للتصوير |
| [`briefs/`](briefs/) | ملخصات الأفكار قبل كتابة النص: الهدف والجمهور والرسالة |
| [`brand/`](brand/) | دليل الهوية: النبرة والألوان والخطوط والشعار |

## سير العمل

1. تبدأ الفكرة بملخص في `briefs/`.
2. بعد اعتماد الملخص يُكتب النص في `scripts/`.
3. يُراجع كل نص مقابل دليل الهوية في `brand/` قبل التصوير.
