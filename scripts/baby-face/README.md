# البيبي فيس - جلسة الدراكولا (Comp 1)

مونتاج كامل على السيرفر بستايل «احدث 3 معلومات عن البوتوكس».

- `bf_timeline.py`: توقيت الكلمات والمشاهد (من تفريغ whisper في after-effects/baby-face-transcript.json).
- `render_bf.py [--sq] [--t=..] [--range=a,b --out=..]`: رندر الصورة (ريلز 9:16 أو مربع 1:1).
- `audio_bf.py`: الصوت (صوت الدكتور + موسيقى + مؤثرات، -14 LUFS).

الأدوات الأصلية والملفات الوسيطة في /mnt/project-files/edits/tools و edits/comp1_work.
