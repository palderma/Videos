# أسباب فشل علاج الكلف وزيادته

أدوات مونتاج ريل «أسباب فشل علاج الكلف» (Medical Editorial، خط «تجمع سوائل» و«الشد المائي v3»).

- `kf.py`: محرك الطبقات والكيفريمات (نفس محرك «الشد المائي»): نفس الوصف بيطلع منه الـ MP4 وسكربت `build_project.jsx` لأفترافكت.
- `kl_edit.py`: المونتاج (القصات على السكتات فقط، التوقيتات، البطاقة الزجاجية، مقطع الجلد والميلانين، الكابشن، الفلاش، زر المراسلة، الخاتمة الوردية + واتساب).
- `kl_grade.py`: تصحيح الألوان (حائط أبيض محايد، زي أقرب للعنابي، بدون تنعيم بشرة).
- `kl_doctor.py`: قص الخام + التلوين + قص الصوت بنفس النقاط.
- `kl_assets.py`: الأيقونات والشعار وملفات المستخدم (فلاش، ماسنجر، واتساب، الخاتمة).
- `kl_audio.py`: تنظيف الصوت والموسيقى تحت الصوت والمؤثرات.
- `kl_render.sh` / `kl_render.py`: ريندر بأربع أجزاء + دمج الصوت.
- `kl_build.py`: مشروع أفترافكت.
- `asr.py`: تفريغ الكلام (whisper large-v3 عبر sherpa-onnx).
