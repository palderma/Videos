# الشد المائي خرافة

أدوات مونتاج ريل «الشد المائي خرافة» (ستايل «تجمع سوائل»).

- `kf.py`: محرك طبقات وكيفريمات بسيط شبه After Effects. نفس الوصف بيطلع منه الفيديو النهائي (numpy/OpenCV) وبيطلع منه سكربت `build_project.jsx` اللي بيبني مشروع أفترافكت بطبقات نص وShape وFootage وPrecomps وكيفريمات حقيقية.
- `sm_edit.py`: المونتاج نفسه (التوقيتات، الهوك، الكابشن، المشاهد، الانتقالات، الخاتمة).
- `sm_assets.py`: الخلفيات والأيقونات والوردة واللوجو.
- `sm_audio.py`: صوت الدكتور والموسيقى تحت الصوت والمؤثرات (‎-14 LUFS).
- `sm_render.sh`: ريندر بأربع أجزاء متوازية + دمج الصوت.
- `sm_build.py`: يكتب `build_project.jsx` لمشروع الأفترافكت.
- `asr.py`: تفريغ الكلام (whisper large-v3 عبر sherpa-onnx).
